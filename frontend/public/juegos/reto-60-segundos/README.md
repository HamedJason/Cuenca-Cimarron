# Reto Mochila de Emergencia 60s

Juego web educativo (HTML5 / JavaScript vanilla) para la campaña de concientización de evacuación por huracán e inundaciones en Tijuana.

## Cómo jugar

1. Abre `index.html` en un navegador moderno, o sirve la carpeta con cualquier servidor estático.
2. Ronda 1: 60 segundos para buscar insumos en cajones de una casa desordenada.
3. Ronda 2: el mismo tiempo, con el kit 72 horas etiquetado en la estación de salida.
4. Revisa la comparativa y el módulo de necesidades específicas.

Capacidad máxima de la mochila: **12 kg**.
